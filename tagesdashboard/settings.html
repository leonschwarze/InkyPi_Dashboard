Aktualisierung und API-Schlüssel
Damit die Zugdaten aktuell bleiben, unter Einstellungen das Wechselintervall (Plugin Cycle Interval) und bei diesem Dashboard das Aktualisierungsintervall auf 5 Minuten stellen. Außerhalb des Zeitfensters zeichnet das Dashboard nur im Takt „Sonst alle … min“ neu (dein gewohnter Takt; InkyPi bekommt dazwischen dasselbe Bild und lässt das Display in Ruhe). Ohne Zug gilt einfach das Intervall der Playlist.
Optional unter API Keys: DB_CLIENT_ID und DB_API_KEY vom DB API Marketplace (kostenlos, Timetables-API). Ohne Schlüssel nutzt das Dashboard die öffentliche Abfahrtstafel der Bahn.

Pause untermin = eine Kette
Termine mit kürzerer Pause gehören zusammen: kein Heimweg dazwischen, ein Verkehrsmittel für alle Wege.
Aufbruch-Kartemin vorher
„Eigene Orte“ hilft, wenn ein Terminort nicht gefunden wird: Steht der Name im Ort des Termins, wird die Adresse dahinter verwendet.
So wird entschieden
Termine, zwischen denen die Pause kurz ist, bilden eine Kette. Mit dem Rad nur, wenn es auf allen Wegen der Kette – mit einer Stunde Abstand – trocken ist: kein Niederschlag, Regenrisiko unter der Schwelle, keine Böen ab 50 km/h, keine Glätte. Sonst Bus und Bahn für die ganze Kette. Termine ohne Ort werden übersprungen. Fahrzeiten und Verbindungen kommen von Transitous (frei, ehrenamtlich betrieben).
